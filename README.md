# Django Admin Terminal POC

This project is a Proof of Concept (POC) built while learning the Django web framework.  
It demonstrates the core components of a Django backend application by implementing a simple Todo management system.

The project covers fundamental Django concepts including:

- Creating a Django project and app
- Defining database models
- Running migrations
- Creating views and URL routes
- Running the development server
- Basic CRUD-style todo functionality

Django provides an automatic admin interface that allows developers to quickly create, view, update, and delete records based on application models, making it useful for internal data management and rapid development.

## Features

- Simple Todo item model
- Django ORM database integration
- URL routing for application endpoints
- Django development server setup
- Beginner-friendly backend structure

## Tech Stack

- Python
- Django
- SQLite (default Django database)

## Purpose

This repository was created as a learning exercise to understand how Django projects are structured and how backend web applications are built using Python.
